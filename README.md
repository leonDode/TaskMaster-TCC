PUCRS - Pós Graduação em Desenvolvimento Full Stack - Projeto de conclusão de curso

Tecnologias utilizadas:

- NestJS
- React
- Vite
- TypeScript
- Prisma
- Supabase
- PostgreSQL
- Zustand
- Tailwind CSS
- pnpm

Rodando o projeto:

pnpm install
pnpm --filter api start:dev
pnpm --filter web dev
pnpm --filter api prisma:generate
pnpm exec prisma studio --schema apps/api/prisma/schema.prisma
